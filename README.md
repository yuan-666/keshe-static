# keshe-static

票务管理系统 — 纯静态演示版

基于原 Vue 3 + Flask 项目改造，去除所有后端依赖与构建步骤，使用纯 HTML/CSS/JS 实现，数据通过 `localStorage` 模拟持久化，可直接部署至 GitHub Pages。

## 功能特性

- **用户购票**：选择班次、填写乘客信息、选择舱位等级与座位区域
- **退票管理**：支持按姓名/班次筛选，发车前 1 小时不可退票
- **班次管理**：管理员增删改查班次，已售票班次不可删除
- **数据统计**：总览卡片（总票数/班次数/容量/售出率）+ 分班次明细
- **CSV 导入导出**：支持 CSV 文件上传解析导入、带 BOM 的中文兼容导出
- **滑块验证码**：登录/注册页拖拽验证组件

## 技术栈

- HTML5 + CSS3 + JavaScript（ES6+）
- 自定义 CSS（无框架依赖）
- localStorage 模拟后端数据

## 设计风格

- Glassmorphism（毛玻璃）侧边栏与卡片
- 渐变按钮与状态徽章
- 固定侧边栏导航（移动端折叠为图标模式）
- 响应式布局

## 项目结构

```
keshe-static/
├── index.html            # 用户登录页（滑块验证码）
├── admin-login.html      # 管理员登录页
├── register.html         # 注册页（滑块验证码）
├── purchase.html         # 购票页
├── refund.html           # 退票页
├── classes.html          # 班次管理页（管理员）
├── stats.html            # 数据统计页
├── import-export.html    # CSV 导入导出页
├── css/
│   └── style.css         # 全局样式
└── js/
    ├── mock-data.js      # 模拟数据与 CRUD 函数
    └── app.js            # 公共逻辑（侧边栏、权限、滑块验证、CSV 处理）
```

## 快速开始

1. 克隆仓库
2. 用浏览器直接打开 `index.html`，或部署至任意静态托管服务
